# Portada de DoctorChart

La portada presenta las funciones clínicas; las cuentas, planes y tickets siguen
en Bycode. Los enlaces se construyen desde `site.applicationUrls.bycode`.
No se publica una demo interactiva ni se anuncia el sistema de turnos pendiente.

Las cuatro imágenes WebP de `public/images/products` se reutilizan de
`bycode-frontend/public/images/products`. Muestran curvas y vacunación con datos
sintéticos de Paciente Demo. No contienen información de pacientes reales.
Ver la procedencia y el proceso de captura en
`bycode-frontend/docs/capturas-productos.md` (26/10/2026).

Se usan las variantes de 720 px en claro y oscuro. Para actualizarlas, regenerar
primero las capturas compartidas y sincronizar estas cuatro variantes.

Bycode tiene rutas de planes, registro y soporte y la sección pública
`/#bc-contact`. No se encontraron páginas públicas de privacidad o términos
en las rutas revisadas; no se agregaron enlaces ficticios ni textos legales.
